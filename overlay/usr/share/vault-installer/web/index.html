Selamat Datang di VaultOS

Sistem Operasi Linux Aman, Immutable (Read-Only), dan Terisolasi Sandbox.

Sistem Read-Only

File sistem host tidak dapat diubah oleh pengguna biasa, tahan malware dan kerusakan sistem.

Sway Wayland & Apps

Window Manager Sway ringan dan cepat, lengkap dengan Firefox & PCManFM terpasang.

Debian Sandbox Terminal

Terminal terisolasi dalam container Bubblewrap, bebas eksperimen tanpa menyentuh host.
